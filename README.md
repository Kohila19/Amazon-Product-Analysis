                                                  Amazon Product Analysis 

A. Project Overview

This project focuses on analyzing Amazon product data to identify patterns and insights related to product categories, pricing, discounts, and customer ratings.

The project includes data cleaning, exploratory data analysis, bivariate analysis, and an interactive Power BI dashboard to present the findings visually.

B. Objectives

* Analyze the distribution of Amazon products across categories
* Understand product pricing patterns
* Analyze discounts offered on products
* Examine customer ratings
* Compare actual prices and discounted prices
* Identify relationships between discounts, prices, and ratings
* Build an interactive Power BI dashboard to communicate key insights

C. Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab
* Power BI
* GitHub

D. Project Workflow

1. Data Cleaning

  The dataset was cleaned and prepared for analysis by handling issues such as:

  * Missing values
  * Duplicate records
  * Incorrect data types
  * Price-related formatting issues
  * Category formatting

2. Exploratory Data Analysis

  Univariate analysis was performed to understand individual variables, including:

  * Product prices
  * Discount percentages
  * Product ratings
  * Product categories

 Statistical measures and visualizations were used to understand the distribution of the data.

3. Bivariate Analysis

   Bivariate analysis was performed to investigate relationships between variables such as:

  * Actual Price vs Discounted Price
  * Discount Percentage vs Rating
  * Category vs Price
  * Category vs Rating

4. Power BI Dashboard

   An interactive Power BI dashboard was created to provide a visual summary of the analysis.

  The dashboard includes:

  * KPI cards
  * Price analysis
  * Discount analysis
  * Rating analysis
  * Category analysis
  * Interactive charts and visualizations

E. Dashboard

 The Power BI dashboard provides an interactive overview of Amazon product pricing, discounts, ratings, and categories.
